# 🎬 OTT Streaming Content Trend Analysis

## 📌 Project Overview

The **OTT Streaming Content Trend Analysis** project explores a streaming content catalog to identify patterns in genre distribution, content types, release-year trends, country representation, content ratings, and movie runtime.

The objective is to transform raw catalog data into meaningful insights and develop actionable recommendations for a content acquisition and strategy team.

**Note:** The included dataset is synthetic and intended for demonstration and learning purposes. It does not represent official Netflix, Amazon Prime Video, or Hotstar data.

## 🎯 Project Objectives

* Analyze genre popularity and content distribution.
* Compare movies and TV shows.
* Explore release-year trends and catalog additions.
* Examine country representation and content ratings.
* Analyze movie runtime patterns.
* Practice data cleaning, exploratory data analysis (EDA), and SQL aggregations.
* Translate analytical findings into business recommendations.

## 🛠️ Tools & Technologies

* **Python:** Pandas, NumPy, Matplotlib
* **SQL:** Aggregations, grouping, filtering, and analytical queries
* **Excel:** Data exploration and summary analysis
* **Jupyter Notebook:** Interactive data analysis

## 📊 Key Analysis Areas

1. Content distribution by type
2. Genre popularity analysis
3. Release-year trends
4. Country-wise content representation
5. Content rating distribution
6. Movie runtime analysis
7. Catalog additions by year
8. Genre distribution by content type

## 🚀 How to Run the Project

**1. Clone the repository**

```bash
git clone https://github.com/Monika-2709/OTT_Streaming_Content_Trend_Analysis.git
cd OTT_Streaming_Content_Trend_Analysis
```

**2. Install dependencies**

```bash
pip install -r requirements.txt
```

**3. Run the Python analysis**

```bash
python src/analyze_catalog.py
```

**4. Open the Jupyter Notebook**

```bash
jupyter notebook notebooks/OTT_Content_Trend_Analysis.ipynb
```
